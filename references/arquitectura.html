Transversal · código, entorno y colaboración

Estructura Cookiecutter Data Science · configuración única en config.py (rutas, fechas, partición, semillas, hiperparámetros) · venv Python 3.12 con requirements.txt de versiones fijas · GitHub Flow: main protegida, todo cambio por Pull Request revisado, Conventional Commits · .gitignore excluye datos, MLflow, modelos y credenciales.

Trazabilidad de cada run

data_version (del manifiesto) + rango de fechas + semilla + hiperparámetros → parámetros; equipo + pregunta + git_commit → etiquetas; gráficas, manifiesto y modelo → artefactos.

Entregas siguientes (fuera de alcance hoy)

Model Registry de MLflow → servicio de predicción (API + Docker) → monitoreo de desempeño y deriva de datos; almacenamiento remoto de datos si el volumen crece.
